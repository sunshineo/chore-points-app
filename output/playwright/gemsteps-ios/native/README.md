## 修复循环与剩余差异

已执行实现→Web对照→记录→修复→复测：
1. 任务胶囊高度、标签字号与间距；修复首卡位置。
2. SwiftUI plain按钮额外淡化及逐层透明度；显式按钮样式＋compositingGroup，复拍确认。
3. 奖励图片与角标叠放顺序、禁用灰色；按Web层级修改，窄屏奖励复拍确认。
4. 弹层高度比Web少约20pt、子控件出现额外阴影；明确最小行高并分组合成，修复后面板448宽、高度接近Web。
5. 两个真实原生测试失败已局部修复并重复通过；未引入第三方依赖或改变持久化架构。

剩余可见差异：字体垂直度量约数像素、系统emoji版本／栅格化、渐变插值、阴影和粒子轨迹；原生安全区、键盘行为不同。
Web Next/Image压缩使部分图像较模糊，iOS使用同一原始PNG较清晰。未宣称像素一致。

**尚未验收，不能整体通过：**
- 真机音效听感、静音／蓝牙／音频中断、飞行模式冷启动。没有安装到用户个人真机。
- 最低部署目标iOS17已构建，但仅在iOS27运行；未执行iOS17运行验证。
- Escape：Device Hub捕获键盘时回到系统主屏，无法证明应用收到Escape；仍保留关闭按钮快捷键，未计通过。
- 窄屏SE软件键盘：已尝试Device→Keyboard两项开关及输入框重开，未显示键盘，未把无键盘截图算通过。iPhone13早期版本软键盘可输入／校验，但最后弹层尺寸调整后的软键盘复测未完成。
- 减弱动态效果与最极端字号未完成完整操作验证。
- 额外“积分不足，无法撤销”提示未获确认，保持未启用。现状本地拒绝、值不变且无新增提示，符合Web最终可见结果。

Mac在验收期间两次重新锁屏；第二次解锁后继续完成目录、横屏、弹层和动画。最后再次锁屏，未绕过系统锁。
