# GemSteps iOS

SwiftUI 单设备本地应用，最低 iOS / iPadOS 17。使用 SwiftData / SQLite
保存逐笔积分、模板设置和自定义条目，不连接 Web 后台，不使用 CloudKit。内置 28 项通用任务、10 项通用奖励；
支持任务与奖励管理、临时加减分、当天同项撤销与跨日累计余额，无 PIN、AI 或统计页面。

## 原生界面（2026-09-20）

- 手机两列大方块；iPad 按可用窗口宽度增加列数。任务与奖励使用同一 LazyVGrid。
- 紧凑头部：积分在左、日期与今日变化在右；手机按钮另排一行，宽屏同排。
  头部下方是等宽的“任务／奖励”原生按钮，再下方才是卡片；不使用 TabView。
  使用系统按钮与字体，紫色页头、多彩卡片和靛紫色选中态；背景跟随深浅色，文字支持动态字号。
- 临时加减分使用系统 sheet；选择 ＋／−，用数字键盘输入最多三位数字，再点 ✓ 确认。
  顶部为 ＋、带符号数字、−，与键盘共用三列，加减按钮与数字键等大对齐；加分绿色、减分红色，未选中使用灰调对应色。
  iOS 18+ 使用系统 fitted presentation 按内容确定弹层尺寸，宽度设上限；高度不足时自动改为滚动。
  iOS 17 保留系统默认 sheet 尺寸，不使用固定高度档位。
  键盘最后一排为 0、退格、✓，三键等大；✓ 跟随加减颜色，无清空键。
  每次可加减 1–999，0 或空值不能确认；超额扣分归零，记录及反馈使用实际扣除值。
  成功后播放庆祝并自动关闭；右上角 × 可直接关闭，保存失败时保留输入并显示错误。
- 成功后全屏遮住应用内容，以大图和分数庆祝约 2 秒，期间阻止重复操作。
  临时加减分在 sheet 内播放庆祝，其余操作全屏播放；系统减弱动态效果下使用淡入。撤销不庆祝、不播放音效。
- 新音效采用 Kenney Interface Sounds（CC0），用 AVAudioPlayer 播放；
  旧 Web 合成 WAV 已删除。来源、映射及许可见 [音效说明](GemSteps/Resources/Audio/README.md)。

旧 Web 逐像素比对不再是验收标准。详细执行与限制见
[原生风格改造记录](IMPLEMENTATION_PLAN.md#9-原生风格改造2026-09-20)。

## 运行与验证

打开 `ios/GemSteps.xcodeproj`，选择 `GemSteps` scheme 和 iPhone / iPad 模拟器，
⌘R 运行、⌘U 测试。模拟器不需要 Apple 登录。项目签名团队已设为 Shi Sun 个人团队（`6NFS3QF8P3`）；真机与发布构建需要在 Xcode 登录有权限的 Apple 账号。

```sh
xcodebuild -project ios/GemSteps.xcodeproj -scheme GemSteps -showdestinations
xcodebuild -project ios/GemSteps.xcodeproj -scheme GemSteps \
  -destination 'platform=iOS Simulator,id=<模拟器 UUID>' \
  -derivedDataPath ios/DerivedData test CODE_SIGNING_ALLOWED=NO
```

从仓库根目录运行以上命令。已在 Xcode 27 / iOS 27 模拟器通过构建和 27 项 XCTest。覆盖积分规则、跨日、数据库重开、
保存失败回滚、损坏库不覆盖、庆祝与音效，以及旧模型数据库迁移、模板初始化／升级、
自定义条目增删改、双语显示、停用／删除后的撤销和分值快照。没有新增第三方代码依赖。

iOS 17 实际运行和真机音效／静音／蓝牙仍待验证；模拟器不代表真机听感与触觉。
应用图标仍是原有低分辨率素材放大的内部开发图标。

## 界面语言

`GemSteps/Localizable.xcstrings` 管理英文和简体中文界面文案，包括按钮、错误提示和辅助朗读。
页头右上角的地球图标提供简体中文、English 两个选项，不单独占一行。
首次启动按系统首选语言初始化并保存：任何中文变体使用简体中文，其他语言使用英文。
后续启动使用已保存的语言，不随系统语言改变；用户可随时手动切换。
切换立即更新界面、日期和辅助朗读，重新打开应用保留选择，不重建积分状态。
日期和星期使用应用语言格式化，积分归属日期继续采用原有洛杉矶时区。
内置任务和奖励的名称包含中英文，随界面语言切换；用户自定义名称始终按原文显示。
英文计数使用 “Points: …” 和 “Count: …” 等格式，避免单复数歧义。

## 固定业务时间

Debug 启动参数 `-gemsteps-date 2026-09-20T19:00:00Z` 固定业务时间，
不影响动画；加 `-gemsteps-date-advances` 可随真实时间前进。Release 不读取这些参数。
不要删除真实设备上的数据来重放测试；测试数据库位于独立临时目录。

## 任务与奖励管理（2026-09-21）

页头的滑杆按钮打开管理页，任务／奖励分别管理；底部工具栏右侧的不透明靛紫色“添加任务／添加奖励”创建对应条目。
管理页不显示标题，任务／奖励切换与关闭按钮共用顶部一行，列表紧接其下。
iOS 26+ 使用系统关闭角色按钮；iOS 17–18 使用不指定额外尺寸的标准叉号工具栏按钮。
每类使用同一个列表，模板与自定义条目混排。每行按“图标、名称、中性色横线、绿色数字、铅笔、开关、排序把手”单行显示，
不显示“分值”标签；名称过长时省略，点击铅笔进入完整编辑页。
所有条目统一使用系统行背景，行间分隔线从行内容左边缘对齐，不随图片或 emoji 图标变化；停用后仅文字、分数与图标灰化，背景不变，仍可编辑、排序和重新启用。
拖动即可保存顺序，日常清单采用相同顺序。停用再启用保留位置，新增条目置于对应列表开头。
升级新增模板追加到已有顺序末尾，仍默认停用；重启与版本更新保留已有条目的相对顺序。
内置模板只允许修改分值和启用状态；名称与图标只读，不可删除。
自定义条目可编辑名称、图标、分值、启用状态，或确认后删除。
名称最多 100 个字符；图标使用一个表情或字符；分值为 1–999 的整数。
任务与奖励属于独立类型，创建后不互相转换。

- `Catalog.swift` 是随 App 发布的双语模板资源，模板 ID 永久稳定；不以名称作为身份。
- SwiftData 的 `TemplateSetting` 保存各模板的分值和启用状态；`CustomItem` 保存完整的自定义内容。
- `CatalogInitialization` 保存初始化标记及可选的条目顺序 ID 列表，排序修改在同一事务中保存。首次使用按模板默认值启用 8 项任务、4 项奖励；
  之后遇到新模板时默认停用。用户全部停用不会触发重新初始化，版本更新不会重置已有分值。
- 旧版没有目录设置，升级时为现有模板建立启用设置，保留原积分流水 ID 和余额。
  `PointEntry` 新增可选字段，通过 SwiftData 兼容迁移保存操作顺序、名称／图标快照和撤销引用。
- 日常清单只显示启用条目。撤销模式只显示当天尚可撤销的操作，包括已停用或删除的条目。
  每次撤销同一条目最新一次未撤销的操作，按原实际分值退款或扣分；卡片显示该次操作的分值。
- 删除自定义条目不会删除流水或改变余额，流水快照继续保留当时的内容。
  旧流水缺少快照时由固定模板 ID 解析名称；日期规则和当天撤销范围保持不变。
- 没有新增独立历史页面、账号或云同步；设置和积分均在设备本地保存。

本轮实测：iPad 上创建测试任务、分值改为 7、停用／重新启用、中英文切换、完成计分、
删除后保留余额，再从撤销模式扣回原 7 分，余额恢复；测试条目已删除。
iPhone SE 小屏已检查主页、管理列表、任务／奖励切换和新增奖励表单；空名称时保存按钮禁用。

## 通用模板（2026-09-21）

模板覆盖自理、收拾与家务、阅读与学习、礼貌与出行。奖励包含选择权、活动、小礼物及可选屏幕活动。
首次默认启用整理床铺、穿衣、穿鞋、洗手、收玩具、晚上刷牙、阅读、按约定时间上床；奖励默认启用贴纸、家庭游戏选择、手工选择、周末活动选择。
其余条目在管理页按家庭需要启用。短任务 1 分、整理或护理 2 分、阅读与练习 3 分；所有分值仍可编辑。
原有家庭专属模板已移除，不转成自定义条目，也不提供旧模板迁移；不清空积分流水。Web 版保持原有内容。

任务模板按起床、出门、回家、学习与收拾、晚餐、睡前的生活顺序混排，不按启用状态分组。
本次更新对已有目录一次性应用新的任务模板顺序，保留自定义条目所在位置、奖励顺序、分值和开关；之后手动排序仍会保存。

## 本地多孩子（2026-09-22）

最多支持 9 个孩子，固定显示“孩子 1”至“孩子 9”（英文 Child 1–9），没有姓名输入、改名或头像。
首页从首次使用起就显示“孩子 1 ⌄”，统一从下拉列表添加、切换和移除孩子；管理页不再提供添加入口。
只剩一个孩子时保留下拉框及其原编号。升级与普通启动不自动创建档案，首次添加时直接创建并切换到孩子 2。
原积分、任务、奖励和顺序全部归孩子 1；每个新孩子统一使用应用默认任务和奖励，从零积分、零完成记录开始，
不复制任何已有孩子的配置或流水。新增按创建顺序编号，达到 9 个后禁用添加，存储入口也拒绝第 10 个。

首页“孩子 N ⌄”紧邻积分；正常字号下宽屏一行、窄屏两行，保留日期、今日积分及全部操作按钮。
无障碍大字号允许更多行，避免挤压控件。点击编号切换，重启记住选择；调整弹层显示对应编号，管理弹层直接显示任务／奖励列表。
已有姓名版档案按原顺序显示编号，UUID、数据库路径、积分及选择不变；语言仍是 App 级设置。

存储沿用现有 SwiftData schema。`FamilyStore` 以 `default.store.children.json` 原子保存孩子列表和选择：
首个档案指向原 `default.store`，其余档案位于 `default.store.children/<UUID>/points.store`。
原账本不搬移、不重写；新账本准备并校验成功后才提交清单。清单提交前失败或取消不启用多孩子。
已有清单损坏或账本缺失时报告错误，不创建空账本替代。备份需保留整个 Application Support 目录。

孩子列表右侧的垃圾桶可移除孩子，确认后删除其积分、流水及配置；至少保留一个孩子。
移除当前孩子时切换到列表中第一个剩余孩子，移除其他孩子时保留当前选择。
孩子列表始终按编号升序显示；已有编号不变，再添加时使用 1–9 中最小的空缺编号，新孩子仍使用默认配置、零积分。
档案清单保留原账本所属 UUID，避免移除首个孩子后读错数据；先提交移除，再清理对应账本，
中断或清理失败时下次启动重试，已移除的档案不会重新显示。
